# Beriday Product Notes

## Product boundary

Beriday is an information service. MVP does not collect, transport, process, broker, or accept payment for waste. It does not use GPS, detailed home addresses, location history, or separate email/password accounts.

## Official schedule source

- Source page: https://www.data.go.kr/data/15075534/fileData.do?recommendDataYn=Y
- Provider: 행정안전부
- Official provider download URL: https://file.localdata.go.kr/file/household_waste_info/info
- Portal metadata checked: 2026-08-27
- Public row count shown by portal: 7,398
- Portal states the data is automatically refreshed and current to approximately two days prior.
- Licence shown by portal: 이용허락범위 제한 없음

The provider download endpoint returned 403 from the current sandbox, so a real raw import has not been claimed as verified here.

## Item guidance source

The initial item examples reference Korean environmental ministry guidance. The production item catalog should be expanded from the official 생활폐기물 분리배출 누리집 rather than generated by AI.
